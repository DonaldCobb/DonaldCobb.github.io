Суть до дела

Зачем
Владимир и Саша смотрят не «красиво ли», а «закрывает ли мою задачу». КП прежнего подрядчика — их список задач. Пульт, где каждая задача находится за 1–3 нажатия, продаёт сам.
Готовое в мире
Телематика техники (Trackunit, Tenna, CAT VisionLink, Wialon) решает простой и моточасы таблицей с полосой смены. Видеосистемы (Avigilon Alta, Verkada, Milestone, QMonitoring) решают «что случилось» лентой событий с клипом. Шлагбаумы (Автомаршал, Terminal Industries) — журнал проездов с кадром номера.
Профи за 15 минут
Выписал бы задачи из КП, к каждой — job story и путь в 3–5 шагов, прошёл бы их по живому пульту и посчитал нажатия. Сделал бы «сценарий показа» из тех же задач — и одну страницу-навигатор «задача → экран».
Образец
QMonitoring (q01–q07, признан Юлаем): вкладки камер, кадр, лента инцидентов на шкале, плитки цифр, рейка разделов слева.
Ловушка
Делать ещё виды «для красоты» (у пульта их уже 7), а не путь к задаче. И обещать в интерфейсе то, чего нет: клипа на простой и редактора зон пока нет.

1 · Метод: job stories + путь задачи

  1. Job story вместо user story: «Когда [ситуация], хочу [действие], чтобы [результат]». Роль не главное — главное, в какой момент человек открывает пульт. Это сразу говорит, что должно быть на экране.
  2. Критерий «решено» к каждой: что человек видит и за сколько нажатий или секунд. Без критерия задача не проверяется.
  3. Путь задачи (task flow) — 3–5 шагов по экранам. Проходим по живому пульту, считаем нажатия, отмечаем, где путь рвётся.
  4. Сценарий показа — те же задачи, только по порядку боли заказчика. На панели — номер задачи у элемента, который её решает.

Персоны и бэклог не нужны: роли и задачи уже заданы КП. Источники (ссылки проверены 25.10, ответ 200): Intercom — Designing features using job stories · NN/g — Task analysis · NN/g — User journeys vs. user flows · NN/g — Task scenarios for usability testing.

«Не понятно, как попасть в разделы» — причина одна

В пульте два мира. Виды пульта — вкладками в шапке. Разделы — рейкой слева на отдельных страницах, и оттуда есть ссылка «Пульт» обратно. А туда пути нет: правило body[data-mode="v2"] … .bar { display: none } прячет панель, где жила ссылка «Разделы». Сценарий показа обходит это заранее открытыми вкладками. Если Саша сам начнёт кликать, он раздел не найдёт.

Как у профессиональных панелей: разделы словами всегда на виду — рейка слева (Milestone, Trackunit, QMonitoring q01/q04), на телефоне — нижняя панель из 4–5 пунктов. Виды одной площадки — переключатель внутри раздела «Площадка», а не 7 соседних вкладок.

4 · Как те же задачи решают профессиональные панели

Цельные экраны живых продуктов: телематика техники (CAT, Trackunit, HCSS, Geotab), видеосистемы (Avigilon Alta, EarthCam, QMonitoring), шлагбаумы и дворы (Terminal, Автомаршал). Отобраны с оценкой 4–5 из 5 против образца QMonitoring. Нажмите на кадр — откроется крупно.

1 Кто на площадке

Приём: цифры площадки над кадрами; машины подписаны рамкой прямо на кадре; график «сколько техники по часам».

У нас: есть; добавить третье состояние и «стоит > 15 мин» отдельной цифрой (Б, В).

2 Журнал проездов с номером

Приём: крупная карточка проезда (кадр + номер + время + действие) рядом с журналом; поиск по номеру — в шапке.

У нас: журнал есть, поиска нет; номер — только с камерой въезда.

34 Событие, клип и разбор

Приём: лента событий «текущие · на проверку · завершённые» с кадром; карточка события: клип с рамками, шкала с отметками, поле «проверено» и статус одним касанием; правило «уведомить, если стоит дольше N».

У нас: вопрос «та же?» есть; ленты простоев с клипом и полем «причина» нет — это прямой образец для задачи 4.

57 Моточасы и простой по машине

Приём: строка на машину: полоса «работа / простой», часы и проценты; сверху — итог парка за день и неделю; «неиспользуемые машины» отдельной цифрой.

У нас: табель «машина × час» есть, но без деления на работу и простой; на главном нет. Таблица машин в Б и В — по этому образцу.

6 Отчёты

Приём: каталог отчётов плитками и «запланированные» — отчёт приходит сам по расписанию.

У нас: отчёты есть, но разбросаны по разделам, из пульта не открыть; рассылки по расписанию нет (кроме сводки в Telegram).

89 План, зоны и карточка машины

Приём: план с зоной объекта и подписанными машинами, рядом список; карточка машины: статус, где она, события, загрузка; состояние каждой камеры отдельно.

У нас: план по зонам камер есть; зону рисовать нельзя; список камер с «нет кадра с …» — только в «Мои объекты».

Экраны: App Store (iPad), справка Trackunit, страницы продуктов. Не нашли цельных экранов Tenna, Milestone XProtect, Genetec и таблицы «машины × часы» у Wialon и Samsara.
