Среда: главный экран

Три компоновки экрана «Сферы» в одной рамке: нижнее меню, цвет ночного моря, крупные иконки. Это визуал — кнопки только переключают экраны.

A · Оглавление

Вопрос «Куда вам?» крупно по морю, под ним все семь сфер столбцом. Смелое место — шапка-вопрос.

Открыть A

B · Мозаика

Плитки сфер: чем больше мест, тем больше плитка; служения по записи — морем. Смелое место — морская плитка.

Открыть B

C · Первая дверь

Светлый блок «Впервые здесь?», лента сфер и весь список подряд. Смелое место — первая дверь.

Открыть C
